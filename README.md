# 🏛️ Document Dash — Seva Setu 🚀

> **An interactive, arcade-style gamified learning experience designed for citizen service awareness in Chhattisgarh.**  
> Master the official statutory prerequisite documents required for essential government certificates on the **Seva Setu** portal!

---

## 🌟 Key Features

- **🎮 Fast-Paced 45-Second Sorting Dash**: Race against the clock to sort official Chhattisgarh citizen documents into their respective certificate baskets.
- **📜 4 Official Statutory Certificates**:
  - 🏠 **Domicile Certificate (निवास प्रमाण पत्र)**
  - 🛡️ **Caste Certificate (जाति प्रमाण पत्र)**
  - 💰 **Income Certificate (आय प्रमाण पत्र)**
  - 💍 **Marriage Certificate (विवाह प्रमाण पत्र)**
- **📑 12 Official Chhattisgarh Prerequisite Documents**: Accurate statutory proof types (Affidavits, Proof of Stay, Education Records, Patwari/Sarpanch Income Proofs, Misal/Adhikar Abhilekh, Vanshvali, Gram Sabha Proposals, Marriage Cards, Photos, Treasury Challans).
- **✨ 3D Dynamic Arena**: Built with Three.js featuring daytime volumetric lighting, geometric physics particles, and ambient visual cues.
- **🎨 Bright Light Theme & High-Legibility Typography**: Curated high-contrast palette (Electric Azure, Vivid Emerald, Saffron Amber, Rose Magenta) with prominent, easily readable typography.
- **🔊 Dynamic Audio Effects**: Synthesized web-audio sound effects for keypresses, drops, combos, countdowns, and trophy unlocks.
- **🇮🇳 Bilingual Support**: Instant seamless toggle between **English** and **Hindi (छत्तीसगढ़ी/हिंदी)**.
- **🏆 Digital Certificate Generation & Scorecard**: Instant generation and inspection of authentic-looking digital citizen certificates with stamps and QR watermarks.

---

## 🛠️ Technology Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **3D Graphics**: [Three.js](https://threejs.org/)
- **Audio**: Web Audio API (Native procedural sound synthesis)
- **Effects**: [canvas-confetti](https://www.npmjs.com/package/canvas-confetti)
- **Styling**: Vanilla CSS (CSS Grid, Glassmorphism, Kinetic CSS Animations)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/dhwanikejriwal/Document-Dash-Seva-Setu-.git
   cd Document-Dash-Seva-Setu-
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
